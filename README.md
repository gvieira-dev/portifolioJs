# 🚀 Portfólio - Gustavo Vieira

Este é o meu portfólio pessoal desenvolvido com o objetivo de apresentar meus projetos, habilidades e informações profissionais de forma moderna e responsiva.

🔗 **Acesse o projeto online:**  
https://seuusuario.github.io/portifolioJs

---

## 🧠 Sobre o projeto

O portfólio foi desenvolvido utilizando HTML, CSS e JavaScript puro, com foco em:

- Interface moderna e limpa  
- Navegação fluida entre seções  
- Responsividade para diferentes dispositivos  
- Experiência do usuário (UX)  
- Animações suaves e interativas  

---

## 🛠️ Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript  
- Git & GitHub  
- GitHub Pages (deploy)

---

## ✨ Funcionalidades

- ✅ Menu de navegação com scroll suave  
- ✅ Seções organizadas (Início, Sobre, Formação, Projetos e Contato)  
- ✅ Cards de projetos com redirecionamento  
- ✅ Formulário de contato com validação  
- ✅ Abertura automática do cliente de e-mail  
- ✅ Layout responsivo  
- ✅ Animações (efeito de flutuação e estrelas no fundo)
